Pandas and SQL treat missing values differently in two cases:

  • A SQL filter such as WHERE a != 'x' drops the rows where a is missing. Pandas keeps them.
  • Pandas groupby leaves out rows with a missing key unless you add dropna=False. SQL counts them as a group.
