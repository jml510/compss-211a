Using this in the notebook

Compare request IDs and group counts to check which rows each query includes. Before joining a lookup table, check for duplicate keys.

In pandas, add validate="many_to_one" to merge() to reject duplicate lookup keys. In SQL, find them with:

SELECT district, COUNT(*) AS rows_per_key
FROM districts
GROUP BY district
HAVING COUNT(*) > 1;
