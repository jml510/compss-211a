✓Remember

  • Every format has its own rules for quotes, commas, and nesting. Use a real reader such as pd.read_csv, not your own splitting code.
  • CSV and TSV don't store types. After loading, check .dtypes, and load ID columns such as case_id as text.
  • JSON can tell "0042" (text) from 42 (a number), can put values inside other values like a Python dictionary, and has null for missing values.
  • XML can also put values inside other values. A missing value can be an empty tag or no tag at all.
  • "Missing" can mean different things: an empty string, null, or a key that isn't there. CSV and TSV turn all of these into the same empty cell.
  • To check that files match, compare row counts, missing values, and column types in your notebook. Looking at the files isn't enough.
