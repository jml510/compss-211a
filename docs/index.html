Skills Checklist & Practice

Review the skills covered so far, practise each one, and save your self-check ratings. Code drills let you write real Python on the course data. New weeks appear automatically.

How Git thinks

Which copy of a repository changes when you save, check, commit, push, and pull: working directory, staging area, local repository, GitHub. Optional tabs cover a refused push, branches and pull requests, a merge conflict, and GitHub Pages.

pairs with: GitHub Desktop · Lab 3 · HW2 · project repo Open Week 4≈ 14 min

Terminal navigator

A practice shell that cannot touch your real files. Move around a small project, see why a script runs from one folder but fails from another, and create, copy, move, and delete files. Then try the same steps in a real terminal with real Python.

pairs with: command line · relative paths · mv and rm Open Week 5≈ 7 min

One dataset, four formats

The same records in CSV, TSV, JSON, and XML. Click a value to find it in each format, then work through the comma trap, the leading zero, and three kinds of missing values.

pairs with: structured data · reconciliation · HW3 Open Week 5≈ 10 min

Do these queries answer the same question?

Seven questions that compare pandas code with the equivalent SQL query: selecting columns, filtering rows, counting groups, and joining tables.

pairs with: structured data · SQL · joins Open Week 5 · in class≈ 70 min

Week 5 SQL workspace

Nine guided SQL steps with SF311 data, followed by a food-access investigation in pairs in DuckDB on your laptop.

pairs with: SQL · joins · Monday class Open Week 5 · optional45–60 min

SQL interview practice

Fourteen SQL practice questions of the kind used in screening tests for data analyst jobs, on a sample of San Francisco 311 data. Queries run in the browser and are checked. Each question can also be answered in pandas.

pairs with: SQL · pandas · job interviews Open Week 6≈ 8 min

Understanding web APIs

Build a bounded OpenAlex-style request, read the response starting from the status code, page with cursors, handle a 429, and keep your API key out of the URL.

pairs with: web APIs · pagination · HW3 Open Week 8≈ 8 min

Understanding TF-IDF

Four campus comments become tokens, counts, and TF-IDF weights as you type. Flip the preprocessing switches and watch the top terms change.

pairs with: NLP fundamentals · HW4 Open Week 9≈ 8 min

How computers learn word meanings

Words as positions, similarity as angles. Compare words, average them into documents, run a small KMeans, and see why you read a cluster before naming it.

pairs with: embeddings · clustering · lab 9 Open Week 12 · optional90 min

Take-home practice

A practice exercise in the format of a take-home test for an analyst job: one data file, three questions, and a short note. You work in your own notebook and the page checks your numbers.

pairs with: pandas · SQL · final project Open
